# Internationalization

This site is bilingual. Spanish (Argentine) is the default and priority
locale and is served at the root (`/`). English lives under `/en/`. Every
public page exists in both locales and each page links to its counterpart
through the language switcher in the header.

## How it is wired

- `astro.config.mjs` declares the Astro i18n routing: locales `es` and
  `en`, `es` as default, no prefix for the default locale.
- `src/i18n/ui.ts` holds the locale helpers (`localeFromPath`,
  `localizePath`, `delocalizePath`) and the shared chrome dictionary
  (navigation, footer, color mode, community links).
- Every page is a component in `src/components/pages/` that receives a
  `locale` prop. Thin wrappers render it: `src/pages/<page>.astro` for
  Spanish and `src/pages/en/<page>.astro` for English. Page copy is
  chosen with `isEs` conditionals in the component.
- `BaseHead` emits `hreflang` alternates (`es`, `en`, `x-default`),
  the matching `og:locale` values and a small script that honors a
  stored language preference.
- The switcher is the ES/EN control in the header. ES carries the
  Argentine flag, never the Spanish one. Choosing a language stores
  `hornero-lang` in localStorage; on the next visit the visitor is sent
  to the same page in that language.

## Adding or changing copy

1. Edit the page component in `src/components/pages/`, not the wrappers.
2. Write the Spanish string first, then the English one. Spanish copy
   uses Rioplatense forms (voseo for imperatives).
3. Localize internal links with the component's `L()` helper. External
   links (GitHub, Vercel Blob, AUR) stay untouched.
4. Product facts still come from `src/data/product/` (generated, never
   hand-edited). Only page-authored copy and label maps live in the
   components.

## Current limits

- Documentation under `/docs/` is rendered from HorneroOS/docs, which is
  authored in English. Both locales serve that content with a localized
  site frame, and the Spanish docs pages show a note saying the
  translation is pending in HorneroOS/docs.
- Pagefind builds a search index per language (es and en).
- The prebuilt OpenGraph cards in `public/og/` are single images shared
  by both locales.
