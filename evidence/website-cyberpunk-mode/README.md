# Cyberpunk Argentina color-mode review

These screenshots were captured from the locally built production site with Chromium 153 at desktop (1440×1000) and mobile (390×844) viewports. They document the shared Buenos Aires-at-night / river-fog daylight design system and its persistent Dark, Light and System control.

- `home-dark.png` — homepage in Dark mode.
- `themes-dark.png` — theme gallery in Dark mode.
- `themes-light.png` — theme gallery in Light mode.
- `themes-light-mobile.png` — theme gallery and all three mode choices at phone width.

The mode selector was also exercised in Chromium: all 45 generated routes were checked in desktop and mobile widths in both Dark and Light modes (180 route/mode/viewport combinations). Dark and Light persisted across route navigation; System followed an emulated dark operating-system preference; every route retained all three choices without horizontal overflow.
